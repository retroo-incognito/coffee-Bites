# Coffee And Bites

A responsive, frontend-only café website built with React and Vite.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The production site is generated in `dist/` and can be deployed to Vercel as a static Vite site. It does not require environment variables, server functions, or backend infrastructure.

## Content and assets

Ordering and directions use the shared links in `src/data/links.js`. The current menu and availability are linked to the restaurant's Zomato listing. Local photography and the favicon are stored in `public/`.
